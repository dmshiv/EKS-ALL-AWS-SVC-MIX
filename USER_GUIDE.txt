CLOUDCART USER GUIDE  (hands-on test manual)
===========================================================================
Nothing in this repository is applied for you. You run every terraform apply yourself:
  scripts/tf.sh <folder> plan  ->  review  ->  scripts/tf.sh <folder> apply
Order of folders: scripts/execution-order.txt.  Explanations: terraform/<folder>/README.md and docs/.
Placeholders in <angle brackets> come from `terraform output` or the AWS console. Test IDs are stable (use them in notes).
Commands marked DESTRUCTIVE delete data. Controlled failures always end with a CLEANUP line that restores the system.
Environment: run `source scripts/env.sh` in every new shell (sets account, region, state bucket, cluster name).
